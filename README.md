# Генерация реалистичных изображений: Гибридная модель VAE-StyleGAN2 с управлением через CLIP

Проект-исследование по созданию и реализации гибридной генеративной архитектуры для генерации высококачественных изображений. Проект объединяет сильные стороны трёх передовых подходов в области ИИ: **VAE**, **GAN (StyleGAN2-ADA)** и **CLIP**.

Главная цель — создать модель, которая не просто генерирует детализированные изображения, но и позволяет точно контролировать их содержание с помощью текстовых описаний.

---

### **Ключевые особенности и архитектура**

* **Гибридная архитектура:** Модель использует **VAE** для создания гладкого и семантически богатого латентного пространства. Затем это пространство подаётся в генератор **StyleGAN2-подобной архитектуры**, который создаёт высококачественные изображения.
* **Управление через текст:** Интеграция модели **CLIP** позволяет управлять генерацией изображений с помощью текстовых описаний, решая проблему семантического контроля в традиционных генеративных моделях.
* **Прогрессивное обучение:** Для стабильности и достижения высокой детализации модель обучается поэтапно, начиная с низкого разрешения (4x4) и постепенно увеличивая его до 128x128.
